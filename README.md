## 4.サービス概要
**RamenShare（ラーメンシェア）** は、全国のラーメン好きが「おすすめの一杯」を共有できる投稿型SNSです。  
お気に入りのラーメンを写真とコメント付きで投稿し、地図上で場所を確認したり、他のユーザーと感想を共有することができます。  

ラーメンが好きで、食べた感動をもっと簡単に共有したい。  
そんな思いから生まれたのが RamenShare で、シンプルで心地よい投稿体験を目指しました。
## 5.開発背景
美味しかったラーメンを、気軽に投稿・記録できるものはないかと思ったのがきっかけでした。<br>
「写真」「感想」「場所」を一体的に管理できるサービスがあれば便利と思い、このアプリの開発を始めました。

## 6.機能
### ホーム画面<br>
・ラーメン投稿一覧: 新着投稿、人気投稿を表示(いいね順に表示)
・ログインユーザーは投稿にいいね可能

### ラーメン投稿<br>
・投稿フォーム(タイトル、説明、ジャンル、住所、画像（複数枚対応）)を入力して投稿<br>
・住所は、地名や店名を入れることで、正確に表示可能

### 投稿詳細<br>
・(タイトル、説明、ジャンル、住所、画像（複数枚対応）)の編集、削除

### ユーザー詳細<br>
・そのユーザーの投稿したもの、いいねしたものを表示<br>
・ユーザー内容の(名前、メールアドレス、アバター画像、パスワード)編集
